# Paradise Nursery 🌿

Paradise Nursery is a React and Redux-based online plant shopping application.

## About the Project

Paradise Nursery is an e-commerce style web application where users can browse different types of plants and add them to a shopping cart.

## Features

- Landing page with Paradise Nursery branding
- Browse plants by category
- Plant images, descriptions, and prices
- Add plants to the shopping cart
- Cart item quantity management
- Increase or decrease item quantities
- Remove items from the cart
- Automatic cart total calculation
- Checkout button
- Continue Shopping functionality
- Responsive design for smaller screens

## Plant Categories

The application includes plants from categories such as:

- Air Purifying Plants
- Aromatic Fragrant Plants
- Insect Repellent Plants
- Medicinal Plants
- Low Maintenance Plants

## How to Run

Install the project dependencies:

npm install

Start the development server:

npm run dev

## Shopping Cart

The shopping cart is managed using Redux Toolkit. Users can add plants, update quantities, remove items, and view the calculated total price.
